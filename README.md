## Technologies Used

## Project Description

## Deployment Steps
1. Created an index.html file.
2. Created a public GitHub repository.
3. Uploaded the website source code.
4. Enabled GitHub Pages from Settings.
5. Selected the main branch and root folder.
6. Verified the published website.
